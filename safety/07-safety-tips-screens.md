# טיפי בטיחות למסכים — create / chat / detail

טון: רגוע, קהילתי, בלי להבטיח «בטוח». עקבי ל־`SAFETY` ב־`src/lib/categories.ts`.

## create (יצירת בקשת עזרה)

**באנר קצר (מומלץ מעל/מתחת לטופס):**
```
טיפ: במפגש ראשון העדיפו מקום ציבורי. ג'סטה מתווכת בלבד — האחריות על המפגש שלכם.
```

**שורה אחת ליד שדה מיקום (אם יש):**
```
אפשר להתחיל עם אזור כללי — כתובת מדויקת רק כשנוח לכם.
```

**פוטר קטן בטופס:**
```
ג'סטה היא מתווכת בלבד, האחריות על המפגש של המשתמשים
```

## chat (שיחה)

**באנר קבוע בראש הצ'אט (קיים / variant chat):**
```
אל תשתפו כתובת מדויקת עד שאתם מרגישים בנוח • דווח/חסום זמינים
```

**טיפ ראשון בצ'אט חדש (אופציונלי, חד-פעמי):**
```
הישארו כאן בהתחלה. אם משהו מרגיש לא נכון — חסמו ודווחו. אין צורך להסביר.
```

**אם מבקשים כסף / מעבר לוואטסאפ בלחץ (טריגר עתידי):**
```
לא חייבים להמשיך מחוץ לאפליקציה או להעביר כסף. דווח וחסום זמינים תמיד.
```

## detail (כרטיס עזרה / פרופיל מציע)

**באנר tip (קיים):**
```
טיפ בטיחות: העדיפו מקום ציבורי במפגש ראשון
```

**ליד תגית אימות:**
```
מאומת בסיסית = אימות טלפון. זה לא אומר שהאדם «בטוח».
```

**ליד כפתורי דווח/חסום:**
```
דווח או חסום בכל רגע — בלי דרמה.
```

**פוטר מסך:**
```
ג'סטה היא מתווכת בלבד, האחריות על המפגש של המשתמשים
```
