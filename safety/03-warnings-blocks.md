# תבניות אזהרות, הגבלות וחסימות

טון: **חם, ברור, תקיף** — לא משפטי־תאגידי.  
ג'סטה מתווכת בלבד; לא מבטיחים תוצאה ולא מתווכים בסכסוך.  
מקומות שדורשים ניסוח מחייב מסומנים `[דורש עו״ד]`.

---

## 1. אזהרה רכה (soft warning)

**מתי:** S1, חריגה ראשונה קלה (ספאם קל, לחץ קל לעבור מחוץ לאפליקציה, טון לא מכבד).

**נושא / כותרת:** הערה קצרה מהקהילה

```
היי,

קיבלנו דיווח על פעילות בחשבון שלך שנראית לא מתאימה לכללי הקהילה של ג'סטה
(למשל: הצפות, לחץ לא נוח, או תוכן לא רלוונטי).

אנחנו מזכירים בעדינות:
• ג'סטה מתווכת בין אנשים — האחריות על המפגש שלכם
• העדיפו שיחה מכבדת, בלי לחץ ובלי בקשות חשודות
• דווח/חסום זמינים לכולם — גם כלפיכם וגם מצדכם

זו הערה בלבד, בלי הגבלה כרגע. תודה שעוזרים לשמור על קהילה שעוזרת — באחריות.

צוות ג'סטה
```

---

## 2. אזהרה רשמית (formal warning)

**מתי:** S2, או חזרה אחרי אזהרה רכה.

**כותרת:** אזהרה — הפרת כללי קהילה

```
שלום,

לאחר בדיקה לפי הכללים שלנו, אנחנו מוציאים אזהרה רשמית לחשבון שלך.

מה לא בסדר (בקצרה): [סיבה קצרה — למשל: הטרדה בצ'אט / בקשות כסף מחוץ לאפליקציה / ספאם]

מה חשוב לדעת:
• המשך התנהגות כזו עלול להוביל להגבלה זמנית או לחסימה
• ג'סטה לא מתווכת בסכסוכים בין משתמשים ולא מכריעה "מי צודק"
• אפשר להמשיך להשתמש — בכבוד ובאחריות

אם לדעתך מדובר בטעות, אפשר להשיב להודעה הזו בקצרה. לא ננהל דיון ארוך.

ג'סטה — קהילה שעוזרת, באחריות
```

> פירוט משפטי של "הפרת תנאים" וזכויות ערעור: `[דורש עו״ד]` בתנאי השימוש.

---

## 3. הודעת הגבלה זמנית

**מתי:** S2 חוזר, S3 ראשוני, או טריגר אוטומטי (ריבוי דיווחים).

**כותרת:** החשבון שלך מוגבל זמנית

```
שלום,

החשבון שלך בג'סטה מוגבל זמנית עד [תאריך/שעה] (או ל־[X] שעות/ימים).

בזמן ההגבלה לא ניתן: [לפרסם בקשות / לשלוח הודעות חדשות / ליצור קשר — לפי מה שמוגדר במוצר].
עדיין אפשר: [לצפות / לדווח — אם רלוונטי].

למה: [סיבה קצרה לפי קטגוריית דיווח — בלי לפרט מי דיווח].

ג'סטה היא מתווכת בלבד. ההגבלה נועדה לשמור על מרחב בטוח יותר לכולם —
לא כדי לפסוק בסכסוך אישי.

בסיום התקופה ההגבלה תוסר אוטומטית, אלא אם יתווסף מידע חדש.

צוות ג'סטה
```

> משך הגבלה סטנדרטי ומדיניות חזרתיות: החלטת מוצר; ניסוח מחייב ב־ToS: `[דורש עו״ד]`.

---

## 4. הודעת חסימה קבועה / באן

**מתי:** החלטת שחר/אדמין אחרי S3 חוזר או S4, או התחזות/הונאה חמורה.

**כותרת:** החשבון נחסם

```
שלום,

החשבון שלך בג'סטה נחסם ולא ניתן להמשיך להשתמש בשירות.

סיבה כללית: [הפרת כללי קהילה חמורה / התחזות / איומים / הונאה — בחר אחד].

מה זה אומר:
• אין גישה לצ'אט, לפרסום או ליצירת קשר דרך ג'סטה
• חשבונות חדשים שמנסים לעקוף חסימה עלולים להיחסם גם הם

ג'סטה מתווכת בין אנשים ואינה צד בסכסוכים. החלטה זו התקבלה לפי מדיניות פנימית.

[דורש עו״ד: פסקה על ערעור, שמירת מידע, וקישור לתנאי שימוש / יצירת קשר רשמי]
```

**גרסה קצרה בתוך האפליקציה (מסך חסימה):**
```
החשבון נחסם לפי כללי הקהילה.
אין אפשרות להמשיך מכאן.
```

## 5. אישור למדווח (בלי הבטחת תוצאה)

**מתי:** מיד אחרי שליחת דיווח (אוטומטי).

```
קיבלנו את הדיווח. נבדוק לפי הכללים שלנו.

תודה ששומרים על הקהילה.
טיפ: אפשר גם לחסום את המשתמש כדי להפסיק ליצור קשר מיד.
```

**מעקב אופציונלי (כשסוגרים תיק — בלי פירוט יתר):**
```
עדכון: התייחסנו לדיווח שלך בהתאם לכללים.
לא נוכל לשתף פרטים על פעולות בחשבונות אחרים.
אם משהו חוזר — דווחו שוב או חסמו.
```

❌ לא לכתוב: "חסמנו אותו", "תוך 24 שע׳", "תקבלו עדכון עם התוצאה המלאה".

## 6. מצבי ריק / מסכים למשתמש חסום או אחרי חסימה

### משתמש שניסה לפתוח צ'אט עם מי שחסם אותו
```
אין אפשרות ליצור קשר עם המשתמש הזה.
```

### רשימת שיחות — צד שנחסם על ידי המשתמש
```
חסמתם את המשתמש. השיחה לא פעילה.
[ביטול חסימה]  (אופציונלי ב-MVP+)
```

### ניסיון התחברות / שימוש בחשבון חסום לצמיתות
```
החשבון נחסם.
לשאלות מדיניות: [דורש עו״ד — כתובת פנייה רשמית]
```

### ניסיון שימוש בזמן הגבלה זמנית
```
החשבון מוגבל זמנית עד [תאריך].
בינתיים לא ניתן לבצע פעולה זו.
```

### אחרי לחיצה על "חסום" (אישור למשתמש החוסם)
```
נחסם. הוא/היא לא יוכלו ליצור איתך קשר מג'סטה.
אפשר גם לדווח אם מדובר בהטרדה או הונאה.
```

### אין דיווחים / תור ריק (אדמין)
```
אין דיווחים ממתינים. יופי 🌿
```
