# ספאם והתחזות — מניעה וטיפול

מטרה: לחסום רעש והונאות **בלי** להבטיח למשתמשים ש"הכל בטוח", ובלי מוקד אנושי עמוס.

## רשימת אותות (signals)

### ספאם / הצפה
- חשבון חדש + שליחת פניות רבות בזמן קצר (blast).
- אותו טקסט מועתק להרבה אנשים / כרטיסים.
- קישורים מרובים בהודעות ראשונות.
- מעבר מיידי לבקשת תשלום / ארנק / ביטקוין / "רק בוואטסאפ".
- פרסום כרטיסי עזרה חוזרים זהים ברדיוסים רחבים בלי הקשר מקומי.
- תגובות לא רלוונטיות לקטגוריה (למשל: "השקעות" תחת גינה).

### התחזות / פרופיל מטעה
- שם זהה או דומה מאוד לדמות מוכרת בשכונה / לעסק מקומי / למשתמש קיים.
- תמונת פרופיל גנובה (אות קלאסי: תמונת סטוק או ידוען).
- טענה לאימות יתר ("אני המנהל של ג'סטה", "מאומת משטרתית") — **אין לנו דבר כזה**.
- בקשה לקוד אימות / סיסמה / SMS בשם "תמיכת ג'סטה".
- פרופיל עם דירוגים שנראים מפוברקים (אם/כשיופיע דפוס).

### הונאה סביב מפגש (גם בלי תשלום ב-MVP)
- "תשלח פיקדון ואז אגיע".
- "תעזור לי רק עם העברה בבנק".
- שינוי מקום ברגע האחרון למקום מבודד + לחץ.

## כללי אוטומציה מוצעים ל-MVP

| כלל | התנהגות מוצעת | חומרה טיפוסית |
|-----|----------------|----------------|
| מגבלת הודעות לחשבון חדש | למשל עד N הודעות ל־M נמענים ב־24 שע׳ הראשונות | soft-limit |
| מסנן הודעה ראשונה | חסימה/דגל אם יש קישור + מילות מפתח לתשלום (ביט, פייבוקס, העברה, קוד אימות) | S1–S2 |
| מגבלת קישורים | מקס׳ 1 קישור להודעה; 0 בהודעה ראשונה בחשבון חדש | soft-limit |
| קצב יצירת כרטיסים | מגבלת כרטיסי עזרה ליום לחשבון חדש | soft-limit |
| דיווחים ייחודיים | ≥K מדווחים שונים ב־24 שע׳ → הגבלה זמנית אוטומטית + תור | S2–S3 |
| התחזות למותג | מחרוזות כמו "תמיכת ג'סטה" / "אדמין ג'סטה" בשם או בהודעה → הסתרה + S3 | S3 |
| חסימת משתמש | מיידי מצד המשתמש; לא עובר בתור | — |

ערכי N/M/K — לכיול אחרי שבועיים של שימוש אמיתי; להתחיל מחמיר יחסית ב-MVP.

### מה לא לבנות ב-MVP
- מודל ML כבד לזיהוי ספאם.
- צוות שקורא את כל ההודעות ידנית.
- "אימות זהות ממשלתי" או בדיקת רקע.

## פלייבוק התחזות

1. **קליטה:** דיווח `impersonation` או כלל אוטומטי על שם מותג.
2. **הסתרה מיידית** של כרטיסים/הודעות חשודים (אם אפשר טכנית).
3. **הגבלה זמנית** על החשבון החשוד + דרישת אימות בסיסי מחדש.
4. **בדיקת תור (קצרה):** האם השם/תמונה מחקים משתמש אחר או את ג'סטה?
5. אם כן ברור → הסלמה לשחר לחסימה קבועה (S3/S4).
6. **למדווח:** תבנית "קיבלנו, נבדוק" בלבד.
7. **לנפגע (אם משתמש אמיתי דווח שמתחזים אליו):**  
   ```
   קיבלנו דיווח על חשד להתחזות לשם/לתמונה שלך.
   אנחנו בודקים לפי הכללים. לא נשתף פרטים על חשבונות אחרים.
   מומלץ: לא לשתף קודים שמישהו מבקש "בשם ג'סטה".
   ```
8. **לעולם לא:** לבקש מהנפגע "לדבר עם המתחזה" או לנהל עימות.

## טיפים למשתמשים — איך לזהות מזויפים

טקסטים קצרים למרכז עזרה / מסך בטיחות:

- בדקו אם השם והסיפור עקביים; חשד לשם של אדם מוכר בשכונה ש"פתאום" מבקש כסף.
- הודעה ראשונה עם קישור תשלום או "רק בוואטסאפ עכשיו" — דגל אדום.
- ג'סטה **לא** תבקש ממכם סיסמה, קוד SMS, או תשלום לעמלה.
- תגית **מאומת בסיסית** = אימות חשבון בסיסי בלבד — לא הוכחה שמישהו "בטוח".
- לא בטוחים? מקום ציבורי, חסימה, דיווח.

**קטע UI אפשרי:**
```
חשד להתחזות או לספאם? חסמו ודווחו.
ג'סטה לעולם לא תבקש סיסמה או קוד אימות בצ'אט.
```

## מה שיווק לעולם לא טוען

| אסור | מותר במקום |
|------|------------|
| "משתמשים מאומתים ובטוחים" | "אימות בסיסי + כלים לדיווח וחסימה" |
| "אנחנו דואגים לבטיחות המפגש שלכם" | "טיפים למפגש אחראי — האחריות עליכם" |
| "פלטפורמה בטוחה ב־100%" | "קהילה שעוזרת — באחריות" |
| "צוות שבודק כל משתמש" | "מתווכת בין אנשים; כלים בידי המשתמשים" |
| "ביטוח / ערבות למפגשים" | לא להזכיר בכלל ב-MVP |
| "נפתור כל בעיה בין שכנים" | "דווח וחסום — בלי דרמה" |

### משפטי שיווק מאושרים (טיוטה)
- קהילה שעוזרת — באחריות
- ג'סטה מתווכת בין אנשים. האחריות על המפגש שלכם.
- טיפ בטיחות: העדיפו מקום ציבורי במפגש ראשון
- אל תשתפו כתובת מדויקת עד שאתם מרגישים בנוח
- דווח וחסום תמיד זמינים
