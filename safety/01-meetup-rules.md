# כללי מפגש בטוח

ג'סטה מתווכת בין אנשים. האחריות על המפגש היא שלכם.  
מטרת המסמך: כללים למשתמשים + קטעי טקסט קצרים ל־UI (עקבי ל־`SAFETY` בקוד).

## לפני המפגש

- העדיפו **מקום ציבורי** במפגש ראשון (קפה, לובי בניין, חנות, תחנת דלק מוארת).
- אל תשתפו **כתובת מדויקת** עד שאתם מרגישים בנוח — אפשר לתאם נקודת מפגש כללית ("ליד הסופר ב…").
- שתפו חבר/ה: איפה אתם הולכים, עם מי, ומתי חוזרים (מיקום חי / הודעה).
- בדקו פרופיל: דירוגים, תגיות, סטטוס **מאומת בסיסית** — זה סימן בסיסי בלבד, לא הבטחת בטיחות.
- בצ'אט: הישארו באפליקציה בהתחלה; היזהרו ממעבר מהיר לוואטסאפ/טלפון עם לחץ.
- אם מדובר בעזרה שדורשת כניסה לבית (בית/מדף, חיות, גינה) — העדיפו נוכחות של אדם נוסף בבית, או דחיית מפגש לבית עד היכרות.

## במהלך המפגש

- הישארו במקום ציבורי / נראה לעין עד שאתם מרגישים בנוח.
- אל תיקחו עמכם חפצים יקרים מיותרים; אל תציגו ארנק/טלפון/מפתחות באופן בולט.
- **אין תשלומים ב-MVP** — אם מישהו מבקש כסף/העברה מחוץ לאפליקציה: עצרו, דווחו אם זה מרגיש לחץ או תרמית.
- אם משהו מרגיש לא נכון — מותר לעזוב. אין צורך להסביר.
- שמרו על גבולות: עזרה בקטגוריה שסוכמה, לא "עוד משהו קטן" שלא הוסכם.

## אחרי המפגש

- סמנו שהעזרה הושלמה (כשייש זרימה כזו במוצר).
- השאירו דירוג/תגית כנה — עוזר לאחרים, בלי לשפוט אישיות.
- אם חוויתם הטרדה, איום, הונאה או התנהגות מסוכנת: **דווחו וחסמו**.
- אל תמשיכו שיחה עם מי שגרם אי-נוחות — חסימה היא כלי לגיטימי.

## זהירות בכסף וחפצים (גם בלי תשלום באפליקציה)

- אל תלוו כסף, אל תעבירו פרטי בנק/כרטיס, אל תשלמו "דמי ביטול" או "פיקדון".
- אל תמסרו מפתחות, תעודות, או גישה לדירה/רכב למי שלא הכרתם.
- בקטגוריות כמו דלק/דרך או הובלה: תאמו מראש מה כלול, והימנעו מתשלום מראש לאדם זר.
- אם מישהו דוחק "רק בוואטסאפ / רק במזומן / רק עכשיו" — דגל אדום.

## דגלים אדומים

- לחץ לחשוף כתובת/טלפון מיד, או לעבור מחוץ לאפליקציה.
- בקשות כסף, קודים, קישורי תשלום, או "תעזור לי עם העברה".
- סיפורים לא עקביים, שינוי מקום מפגש ברגע האחרון למקום מבודד.
- פרופיל חדש עם הצעות רבות מאוד / טקסט מועתק / שם שנשמע כמו דמות מוכרת בשכונה.
- סירוב למקום ציבורי בלי סיבה סבירה.
- הודעות מאיימות, מיניות, או חוזרות אחרי שביקשתם להפסיק.

**מה לעשות:** עצרו את השיחה → חסמו → דווחו. אל תתווכחו.

## טיפים קצרים לפי קטגוריה (אופציונלי ב-UI)

| קטגוריה | טיפ קצר |
|---------|---------|
| דלק/דרך | נקודת מפגש מוארת וציבורית; אל תעלו לרכב של זר במפגש ראשון אם לא בנוח. |
| הובלה | פרטו מראש משקל/מדרגות; אל תפתחו דלת לבד אם אתם לבד בבית ולא בנוח. |
| בית/מדף | העדיפו נוכחות נוספת בבית; אל תתנו מפתחות. |
| קניות/סידורים | אל תמסרו כרטיס אשראי; רשימה ברורה מראש. |
| גינה / חיות | תאמו שעות ושער/כניסה; אל תשתפו קודים קבועים. |
| דיגיטלי | אל תשתפו סיסמאות / קודים חד-פעמיים. |
| שכונה / אחר | אותם כללי מפגש ראשון. |

## קטעי העתקה ל־UI

### באנר (variant: `tip`)
```
טיפ בטיחות: העדיפו מקום ציבורי במפגש ראשון
```

### טיפ בצ'אט (variant: `chat`)
```
אל תשתפו כתובת מדויקת עד שאתם מרגישים בנוח • דווח/חסום זמינים
```

### פוטר / פרופיל (variant: `footer`)
```
ג'סטה היא מתווכת בלבד, האחריות על המפגש של המשתמשים
```

### מוטו (שיווק / מסך אודות)
```
קהילה שעוזרת — באחריות
```

### תוספות קצרות (אופציונלי — לא בקוד עדיין)

**בכרטיס עזרה לפני יצירת קשר:**
```
מפגש ראשון? תאמו מקום ציבורי. ג'סטה מתווכת — האחריות עליכם.
```

**לפני שיתוף מיקום מדויק:**
```
רק כשאתם מרגישים בנוח. אפשר להתחיל מנקודת מפגש כללית.
```

**ליד כפתור דווח/חסום:**
```
משהו לא מרגיש טוב? דווחו או חסמו — בלי דרמה.
```

**תגית אימות:**
```
מאומת בסיסית
```
> משמעות למשתמש (טולטיפ): אימות בסיסי של חשבון — לא בדיקת רקע ולא הבטחת בטיחות.

**לאחר דיווח (אישור קצר):**
```
קיבלנו את הדיווח. נבדוק לפי הכללים שלנו.
```
> בלי הבטחת תוצאה או לוח זמנים משפטי.
