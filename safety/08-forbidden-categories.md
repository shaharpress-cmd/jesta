# קטגוריות אסורות / אדומות — MVP

מטרה: מה **לא** לאפשר בבקשות עזרה / הצעות, ומה לסמן כאדום (אזהרה או הסרה).

## אסור לחלוטין (להסרה / דחייה)

| נושא | דוגמאות | למה |
|------|---------|-----|
| **קטינים** | עזרה לקטין בלי מבוגר אחראי ברור; מפגש עם קטין; בקשות שקשורות לקטינים בצורה מינית/חשודה | סיכון גבוה · S4 אם חשד |
| **מיני / פגיעה** | כל בקשה או שיחה מינית, הטרדה, תוכן פורנוגרפי | `inappropriate` / `harassment` |
| **אלימות / נשק / פשע** | בקשות לפגיעה, איומים, סיוע לעבירה | `threats` · S3–S4 |
| **סמים / חומרים אסורים** | רכישה, הובלה, ייעוץ | אסור |
| **הונאה / כסף במרמה** | «העבר כסף ואחזיר», פישינג, קודים | `scam` |
| **התחזות** | להתחזות לעסק/שכן/מנהל ג'סטה | `impersonation` |

## אדום — לא מתאים לג'סטה (עזרה שכונתית, בלי תשלומים ב-MVP)

| נושא | דוגמאות | טיפול מומלץ |
|------|---------|---------------|
| **מקצוענים בתשלום / שירות עסקי** | אינסטלטור במחיר, עו״ד, רופא, שיפוצניק כעסק | לדחות או להסביר: ג'סטה לעזרה שכונתית, לא לוח מודעות בתשלום. ב-MVP אין תשלומים. |
| **עבודה בשכר / משרות** | «מחפש עובד», סידור עבודה קבוע | מחוץ לסקופ |
| **הלוואות / השקעות / קריפטו** | הלוואה, «השקעה מהירה» | אסור · `scam` אם לחץ |
| **רפואה / ייעוץ מקצועי מסוכן** | אבחון, תרופות, ייעוץ משפטי כתחליף לעו״ד | להפנות החוצה; לא לאפשר כ«עזרה» |
| **כניסה לבית של אדם לבד + לחץ** | לא אסור אוטומטית, אבל **טיפ חובה** + דגל אם יש לחץ | באנר בטיחות בקטגוריות בית/חיות/גינה |
